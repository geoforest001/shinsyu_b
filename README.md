# shinsyu_b
長野県 動植物 分布マップ（GitHub Pages）

- `index.html` : 地図ページ（一般分布レイヤ＋絶滅危惧種レイヤを1枚に重ねて表示、個別にオン/オフ）
- `data/nagano_outline.geojson` : 白地図用の県境線
- `data/nagano_mask.geojson` : 県外を薄く表示するためのマスク（境界: dataofjapan/land）
- `slope.js` : 傾斜図（ブラウザ内計算）。国土地理院の標高タイル（z14まで dem_png、z15 は dem5a/dem5b の5m）を読み、Horn 法で傾斜角を求めて色を付ける。区分は「標準7区分／歩きやすさ／指定角度以上を強調」から選べる。ズーム11以上で表示
- `data/slope_tiles/` : 傾斜区分図の事前計算タイル(z7-13)。縮小表示（ズーム11未満・標準7区分のとき）だけに使う。国土地理院DEM10mの傾斜角を長野県で切り抜き、0-3/3-8/8-15/15-20/20-30/30-40/40°以上に区分
- `route.js` : 調査ルート案内（試作）。ブラウザ内で経路探索（車→駐車→徒歩→道なし区間）
- `data/route/suwa_graph.json` : 諏訪湖周辺（北緯35.93–36.17°・東経137.95–138.27°）の道路グラフ。`tools/build_route_graph.py` で OpenStreetMap から作成
- `data/grid_nagano.geojson` : 県内545セルの約5km(0.05°)メッシュ（危惧種の記録数・種数・カテゴリ別、一般記録数、平均傾斜・急傾斜率(30°以上)・緩傾斜率(8°未満)、市町村名）

## データ
- 出典: GBIF (https://www.gbif.org) 出現記録、IUCNレッドリスト CR/EN/VU、2026-11-07取得
- 希少種保護のため、個別の位置は公開せずメッシュ集計のみ掲載
- 県名が空の記録は、長野県を囲む矩形内であれば含めているため、県境付近で他県の記録が混じる場合があります

一般分布は GBIF の密度タイル(API)を表示しており、データは同梱していません。

## 調査ルート案内（試作）
- パネルの「ルート案内を開く」（または最初のメニュー）で、左にルート案内のサイドバーが開きます。
- 出発地と目的地を決めて「案内」を押すと、車で行ける所まで車、そこから徒歩、道のない区間は直線で表示します。
  - 決め方：地名・住所の検索（国土地理院の地名検索API）、「緯度,経度」の入力、現在地（出発地のみ）、地図で選ぶ、メッシュのポップアップの「ここを出発地に／目的地に」
  - ピンはドラッグで動かせます。案内中に動かすと経路を引き直します。
- 経路は「車」と「徒歩」の2つの状態を持つダイクストラ法で求めます。駐車地点は自動で決まります。目的地の周り2.5km以内の道から、到着までの時間が最短になる点を選びます。
- 速度の目安：林道・農道 12km/h（車）、徒歩 4km/h、登山道 2.5km/h、道なし 1km/h（いずれも平地）。
- 徒歩の時間は登り下りを考慮します（Tobler の歩行関数）。道ごとの係数は `tools/add_route_elevation.py` が国土地理院の標高タイルから計算し、グラフの `tob` に入れています。車道は橋・トンネルで地表とずれるため、勾配を±20%までに抑えています。
- 道のない区間は、ブラウザで標高と傾斜を読みます。30°以上の斜面を横切ると時間を増やし（40°以上は4倍、45°以上は10倍）、急斜面を避ける地点から歩き出すようにしています。30°以上を通る部分は赤い線で示します。
- 徒歩区間の標高断面図（登り・下りの合計）を表示します。
- 路面状況・積雪・藪の濃さは考慮していません。
- 道路データ：© OpenStreetMap contributors（ODbL）。林道は通行止め・ゲート閉鎖のことがあるため、入山前に管理者へ確認が必要です。

### 道路グラフの作り直し
```
python3 tools/build_route_graph.py              # Overpass API から取得して data/route/suwa_graph.json を作成
python3 tools/build_route_graph.py --area ina   # 伊那IC周辺（data/route/ina_graph.json）
python3 tools/add_route_elevation.py            # 作り直したグラフに登り下りの係数を書き足す（標高タイルは tools/.dem_cache/ に保存）
```
`add_route_elevation.py` は HTTPS で標高タイルを取得するため、SSL 付きの Python で実行してください（macOS なら `/usr/bin/python3` で動作確認済み）。
GeoJSON ではなく、座標を約1m単位の整数にして差分で並べた独自 JSON にしています。諏訪湖周辺では、同じ内容の GeoJSON 8.65MB（gzip 1.23MB）に対して 1.60MB（gzip 0.60MB）です。
